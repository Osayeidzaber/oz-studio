# OZ Studio

The site for [ozstudio.cc](https://ozstudio.cc), the independent design and development practice of Osayeed Zaber.

Next.js 16 (App Router, static), React 19, GSAP + ScrollTrigger, Lenis smooth scroll. Black only: the tokens live at the top of `src/app/globals.css`.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build
pnpm typecheck
```

## Where things are

- `src/data/studio.ts` holds all the copy: live sites, the project index, services and steps. Facts only, no invented clients or numbers.
- `public/work/` holds the full-page captures of each live site (`<slug>-full-desktop.jpg`, `<slug>-full-mobile.jpg`) and a cover (`<slug>-live.jpg`). Most of these sites refuse to be framed, so the showcase scrolls a real capture and links to the live site. Re-capture after a site changes and update the heights in `studio.ts`.
- `src/components/` has one file per section, plus the motion layer (`smooth-scroll`, `preloader`, `cursor`, `magnetic`, `reveal`).

## Motion notes

- Lenis runs on GSAP's ticker, so ScrollTrigger and the scroll share one loop. Anything that should scroll natively inside the page (the showroom viewer) carries `data-lenis-prevent`.
- The showcase pins and runs sideways above 960px; below that, it's a vertical stack. Each capture scrolls with your scroll through `containerAnimation`.
- `prefers-reduced-motion` turns off smooth scroll, the intro and all scroll-linked motion.
- `reactStrictMode` is off: the double mount in dev breaks the showcase pin.

## SEO

- `/osayeed-zaber` is the founder page (`/about`, `/founder`, `/osayeed`, `/zaber` and a few spellings redirect there). It's what should rank for searches of the name.
- `src/lib/seo.ts` builds one schema.org graph (Organization + Person + WebSite with shared `@id`s) used by both pages, so Google treats the studio and its founder as linked entities.
- `sitemap.xml`, `robots.txt`, the web manifest and the share images (`opengraph-image.tsx`) are generated by Next. Bump the date in `src/app/sitemap.ts` when content changes.
- After deploying: add the domain in Google Search Console, submit `https://ozstudio.cc/sitemap.xml`, and request indexing for `/osayeed-zaber`. Link to `ozstudio.cc/osayeed-zaber` from GitHub, Instagram and the personal portfolio; those backlinks matter more than anything on the page.

## Admin: invoice desk

`/admin` makes invoices entirely in the browser: a live PDF (seven designs, Latin and Bengali fonts) and a ready HTML email. Nothing is sent from the site — copy the email, paste it into Gmail or Outlook, attach the PDF and send it yourself.

- Set `ADMIN_PASSWORD` in Vercel (any username works at the browser prompt). Without it, `/admin` is closed in production and open in local dev.
- Invoices and studio details are saved in that browser's local storage. Use **Saved → Export backup** to keep a copy or move to another machine.
- The engine lives in `src/lib/invoice/` (carried over from the portfolio's studio desk); fonts are in `public/fonts/`.
